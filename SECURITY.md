# Sécurité

Pour une faille de sécurité, **ne créez pas de ticket public** : utilisez « Security » → « Report a vulnerability » sur la page GitHub du dépôt
(signalement privé). Nous répondons dès que possible.

L'application ne collecte aucune donnée personnelle sur un serveur : la position GPS reste sur le téléphone et n'est envoyée qu'aux services
d'adresse et d'itinéraire en navigation libre (voir README).
